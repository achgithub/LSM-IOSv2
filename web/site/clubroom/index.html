SPORTS MANAGER

CLUBROOM

League and knockout management for your club.

Set up leagues and knockouts for any club or pub game — venues, teams, players, fixtures, standings and awards, all handled. Define the format once with a Sport Pack, then let the app run the season.

Leagues Round-robin, points, standings and awards, scheduled or open.
Knockouts Single elimination brackets that run alongside your leagues.
Sport Packs Build the format for any game — your own scoring, your own rules.
Player Submissions Send players a link to submit their own result — no app install needed.

Comes with Darts, Pool and Cribbage built in as ready-made examples — everything else is a format you define yourself.
